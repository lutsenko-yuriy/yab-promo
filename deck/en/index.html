1 · Purpose

Agents can write code. Who runs the process?

  • An agent on its own skips planning, tests and review when it's in a hurry
  • Every session starts from zero: no backlog, no memory of past decisions
  • One person can't review everything an agent produces

1 · Purpose

YAB is a GitHub template

Skills

Each step of the job is a skill: brief, plan, implement, review, ship

Workflow

Tickets, work units, TDD, one PR per work unit

Memory

Knowledge base, decisions and debriefs live in the repo

Gate

/onboard must configure the project before anything else runs

1 · Purpose

Five skill families

configure

onboard, calibrate, style, skill-creator

design

brief, analyze, plan, research, experiment

build

implement

verify

review, audit, draft-scenarios

manage

summarize, ship, debrief, note, checkup

Skills ask for an effort tier and a reasoning depth, not a model name. You map tiers to the models you have once, with /calibrate.

2 · Example

One ticket, several work units

/summarize/brief/plan WU0WU1…N/debrief/ship

/brief turns a rough idea into a scoped ticket, one question at a time.

/plan splits it into work units, each with its own branch and PR. You approve the plan before any code is written.

2 · Example

WU0 comes before any production code: red integration scenarios for the user-facing flow, or a verification checklist for everything else.

2 · Example

One ticket, several work units

/summarize/brief/plan WU0WU1…N/debrief/ship

Each work unit repeats the same loop:

red testgreenrefactor + commit PR/review + /auditfixes

Intermediate work units are tagged [wip], so testers never get half a feature.

2 · Example

One ticket, several work units

/summarize/brief/plan WU0WU1…N/debrief/ship

/debrief runs a short retrospective and saves what was learned to the knowledge base.

/ship closes the ticket, writes the changelog, bumps the version and merges.

4 · Limits draft, to be confirmed

What it can't do yet

  • Tested by one developer working with agents, not by a team
  • GitHub is the only Git host; Linear or GitHub Issues are the only trackers
  • Used mostly with Claude Code; other agents are less proven
  • Needs Python 3.11+, and Claude Code must be started from the repo root
