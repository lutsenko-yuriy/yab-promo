## Findings

### Accessibility

- **Finding:** the light green `--yab-growth` (`#8bc34a`) is used for the arrows between lifecycle steps (`.flow-node::after`), the chain and pact arrows, the bullet markers and the progress bar. On the page background (`#f1f8e9`) it reaches 1.93:1, under the 3:1 WCAG 1.4.11 asks of graphics needed to understand the content, and faint on a projector. Text contrast passes everywhere (lowest: dark text on green chips, 4.68:1), state is not shown by colour alone (screen-reader "(done)" text, `aria-current`, the "human" badge on gates), and the controls have focus styles and honour reduced motion.
- **Debt quadrant:** inadvertent × prudent
- **Disposition:** deferred — see ledger Open findings, deadline `2027-01-14`. A visual design call: for example Light Green 800 (`#558b2f`, 3.78:1) for the arrows only, keeping `#8bc34a` for fills.
- **Graduation candidate:** yes — a deck test computing contrast for each `color:` / `background:` token pair in `theme.css`

### Knowledge-corpus bookmark health

- **Finding:** `onboarding-guide.md` had no `bookmarks:` key and `INDEX.md` was stale (YP-2's `scope-growth` missing), so `scripts/notes/index.py --check` failed. Both notes record a recurring theme with no bookmark: a fix to a YAB framework file that should also go upstream (the README launch advice, `--no-track`, and four of this checkup's findings).
- **Debt quadrant:** inadvertent × prudent
- **Disposition:** fixed inline (commit `afa8821`): new bookmark `upstream-candidate`, the onboarding note tagged with it, index regenerated, `--check` passes. `scope-growth` stays: used once, still meaningful.
- **Graduation candidate:** yes — run `python3 scripts/notes/index.py --check` in CI
