## Findings

### Scenario quality

- **Finding:** `scripts/onboard/tests/test_remote.py::test_url_sets_origin` fails in Claude Code cloud containers. The test, and `onboard.py`'s own origin checks, read the remote with `git remote get-url`, which applies `url.<base>.insteadOf` rewrites from the host's git config (the container injects `git@github.com:` → `https://github.com/`). The test passes once that config is removed.
- **Debt quadrant:** inadvertent × prudent
- **Disposition:** deferred — see ledger Open findings, deadline `2026-12-01`. YAB framework file: fix upstream in yuriys-agentic-boyz (read `remote.origin.url` raw, or isolate the test from host git config).
- **Graduation candidate:** no

### Glossary/naming drift

- **Finding:** `docs/GLOSSARY.md` was still empty after YP-2, while the deck's code and docs use a set of terms (section opener, section label, work-unit track, string table) and code names that differ from the visible copy (`eyebrow.*` for the section label, `limits` for "Plans for the future", `toc` for the contents slide).
- **Debt quadrant:** inadvertent × prudent
- **Disposition:** fixed inline (commit `afa8821`): glossary section for the deck with code symbols and aliases to avoid. The code names stay: `limits` and `toc` are in public slide URLs.
- **Graduation candidate:** no

### Doc-reality drift

All pass.
