- 2026-10-24: How the case numbers are counted (agreed with Yuriy; use the same methods on every recount so the numbers stay comparable). Run against each app's default branch (`habit-loop`: `main`, `mordovorot`: `master`) after a `git fetch`:
  - **Releases:** versions in `docs/CHANGELOG.md` that have at least one entry not tagged `[wip]`; versions whose entries are all `[wip]` are steps of a multi-WU ticket, not releases.
  - **Merged pull requests:** `gh pr list -R lutsenko-yuriy/<repo> --state merged --limit 2000 --json number -q length`.

  - **App languages** (Habit Loop): `lib/l10n/app_*.arb` files. **First commit:** the oldest commit on the default branch.

**What was hard or surprising**
